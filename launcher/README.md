# WiiUNX2 0.3 — experimental menu replacement

This is a compiled `men.rpx` replacement based on launchiine. It renders a new HOME screen on the TV and GamePad: horizontal 256-pixel software cards, smooth scrolling, a compact nine-icon dock, rainbow shortcut focus ring, light gray background, clock, network status, and a discrete GamePad battery gauge. All icons in `nx*.png` are original drawings generated by `tools/Generate-Icons.ps1`.

This is a functional prototype, not a complete reimplementation of Nintendo's menu services. The RPX has been cross-compiled and its shared navigation geometry has passed native C++ tests. It has **not** been run on a Wii U or emulator. The previously tested Men.pack/Men2.pack theme remains separate and unchanged.

## Install an isolated Aroma test environment

Use the packaged `Install-SD.ps1` on your computer, with the SD inserted:

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-SD.ps1 -SDRoot E:\
```

Replace `E:\` with your actual SD root. The script copies your existing `wiiu/environments/aroma` to **`wiiu/environments/aroma-wiiunx2`**, excluding plugins and any existing `men.rpx`. It then places WiiUNX2 at `wiiu/environments/aroma-wiiunx2/men.rpx`. It refuses an existing destination and does not alter original Aroma or internal storage. The package includes no Nintendo system files or Aroma binaries.

Hold **X** while starting EnvironmentLoader, then select **aroma-wiiunx2** for the test. Keep normal Aroma as your default. Configure your normal user/default account in the stock menu before testing.

Why no plugins? Homebrew on Menu contains a physical function hook at a stock menu code address. Other menu plugins can make similar assumptions. A replacement RPX has different code at those addresses. Do not enable menu-targeting plugins in this test environment until their compatibility is established. This also means this build does not show Aroma `.wuhb`/`.rpx` homebrew shortcuts.

To roll back, power off, select ordinary **aroma** in EnvironmentLoader, and remove only `wiiu/environments/aroma-wiiunx2` from the SD if no longer wanted. If the replacement hangs, power off and remove its `men.rpx` using a computer before booting again. Never copy it into the console's internal `mlc01` or install it with a title installer.

## Controls and real Wii U equivalents

- D-pad / left stick: move between software cards and the dock. A opens; B returns to the software row.
- L / R: move four titles. Plus opens title details or navigation help.
- GamePad touch or Wii Remote pointer: select once, activate with a second click/tap.
- Dock: Friend List, Browser, Download Management, eShop, Mii Maker, Data Management, controller pairing, System Settings, Power.
- Power opens a confirmation dialog. B cancels; A shuts down.
- Profile button opens Mii Maker; it does not switch accounts.

The dock preserves the reference's spacing and colored outline style with Wii U functions. It does not offer Switch Online, GameChat, GameShare or Switch 2 games. Access to an installed system application does not restore discontinued online services. The network symbol shows connection availability, not measured Wi-Fi signal strength; the battery gauge uses VPAD's discrete levels, not a percentage.

Installed game icons and metadata are read from the console. Game launch uses MCP validation, ACP patch assignment, and SYSLaunchTitle; applets use their system switch APIs. The row also includes installed system applications. Standard Wii U launch/overlay screens remain outside the custom HOME screen.

## Limits that need console work

No account switcher, folders, persistent sorting, title-update workflow, disc insertion refresh, quick-start integration, parental-controls UI, or native Aroma homebrew discovery is implemented. Enumeration is a startup snapshot; reconnect storage and restart after changes. Launchiine's reliance on the environment's account/storage initialization remains. Region-aware title enumeration avoids hard-coded USA game IDs, but region and hardware behavior are untested. This is an experimental replacement, not a proven daily-use menu.

## Build from the complete source bundle

The bundle contains `launcher/` and the modified `dependencies/libgui/` source. Use devkitPro MSYS2:

```sh
pacman -S --needed wut ppc-freetype ppc-glm ppc-libgd ppc-libjpeg-turbo ppc-libpng ppc-libmad ppc-libvorbisidec ppc-libogg ppc-bzip2 ppc-zlib
cd dependencies/libgui
make -j4
cd ../../launcher
make -j4
```

Output: `launcher/men.rpx`. Modern FreeType requires HarfBuzz/Brotli (installed as dependencies); the Makefile links them. libgui's old `-Werror` was removed for newer GCC warnings, and a read-only GamePad battery accessor was added. Existing icon PNGs are included; regenerating them is optional and uses Windows PowerShell plus System.Drawing.

Host tests (a native g++ compiler):

```sh
g++ -std=c++17 -O2 launcher/tests/navigation.cpp -o navigation-test
./navigation-test
```
